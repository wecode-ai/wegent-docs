协作体验预览

“协作 exp”是独立实验标签，集中查看助理、任务、项目、任务时间线与私人讨论。现有“协作”和“我的助理”入口继续可用。

开启与回退​

  1. 打开 左下角账户菜单 → 设置 → 个人 → 通用，开启 实验性功能，再开启 协作体验预览。开关立即保存到当前设备。
  2. 在同页的 固定标签页 → 添加固定标签页 选择 协作 exp，或在顶部标签栏点击 + → 协作 exp。固定标签会在启动时恢复，也可选择为启动项。
  3. 需要回退时关闭 协作体验预览。实验标签与添加项立即隐藏，实验页停止挂载；再次开启会恢复保存的标签、项目和任务位置。

预览对应 collab.experience.v1，默认关闭。仅开启“实验性功能”不会开启预览。已开启的预览始终保留此关闭开关，即使随后关闭“实验性功能”也可回退。关闭预览保留项目、任务、私人会话及标签记录，原“协作”页仍可读取这些数据。

助理与助理团​

  1. 在“协作 exp”左侧选择 助理，进入 我的助理团。在底部输入问题或目标，使用 自动分工 或选择已配置的专业助理，再点击发送。模型选择保留在输入区的紧凑菜单中，加载或失败时仍可进入恢复。首条消息进入当前账号所选助理的私人会话；普通问答不会自动创建项目任务。空白输入不会创建会话。
  2. 未发送的首页输入按当前账号、助理身份及执行设备保存。切换到任务、切换标签、刷新或重启后，返回同一身份可继续编辑。会话内的输入草稿独立保存，不会填入其他讨论。
  3. 待你决定 展示待处理问题及配置提案。点击任务条目进入该任务时间线，通过相关私人讨论继续处理问题；点击 查看具体变更提案 检查具体变更，再选择 确认并应用 或 暂不应用。过期提案需要重新生成；变更应用前不会生效。
  4. 点击顶栏 最近讨论 展开已有私人讨论，或从首页 最近进展 继续工作。关联项目任务的讨论会打开同一项目、同一任务及同一个私人会话，并恢复它的草稿；独立助理讨论留在助理会话面板。来源或当前账号权限无法确认时，使用 重试 重新读取。

首页的 团队接力 展示各助理的 待确认、推进中 或 待命 状态，状态来自已有工作与待决提案。来源尚未就绪时显示 状态尚未确认，快照计数显示“—”，不会把未知当成待命或零工作；读取失败时可重试。宽栏中的 当前工作 汇总待决、推进中和已完成的助理工作，点击正在推进的工作继续原会话或对应执行。手机和窄栏收起详细快照，优先保留紧凑团队条、第一项待决和底部输入区。

点击顶栏 管理助理团，或在团队条点击管理按钮、成员，展开角色列表。列表中的 配置 或角色旁的配置按钮进入原有“我的助理”配置页，按该页的保存操作更新身份、模型及项目范围。默认助理始终保留，不能删除或暂停。专业助理的删除按钮会打开 删除专业助理？，确认 删除角色 才会保存；取消保留现有配置。删除后，已有讨论与执行历史继续保留，默认助理按已有项目范围承接工作。

任务、项目与时间线​

左侧切换 助理 与 任务；点击当前导航项会返回对应首页，并保留任务列表筛选与项目范围。任务列表顶部的查看方式可切换 任务 与 按项目看。点击搜索图标展开搜索、相关性、状态和项目筛选；默认范围为 与我有关，也可切换到全部可见任务。状态分组与相关性分别保留，清除一个筛选不会清除其他条件。任务沿用原项目数据与权限。

顶部 + 或任务首页的 创建任务 打开任务创建表单。项目默认 暂不归属项目，创建为本机独立任务；也可选择实际的本地或云端项目，保存到该项目。填写交付目标，按需修改负责人、截止日期和交付摘要，再点击 创建并打开任务。默认负责人是自己，截止日期是明天。

宽屏未选中任务时，右侧任务首页显示当前列表的 轮到我了、推进中、已结束 数量和当前执行项，随现有筛选更新，不包含无权查看或尚未加载的任务。点击当前执行项或 下一件需要你判断的事 进入对应任务时间线，并保留筛选和项目范围。其下的紧凑 团队接力 与助理首页共用状态规则，团队状态不随任务筛选改变；点击成员进入其原有配置，不会创建讨论或任务。手机未选中任务时保留任务列表，选中后进入下一层。

点击任务查看时间线；点击任务所属项目，或将列表查看方式切换为 按项目看 后选择项目，查看项目概况、计划或配置。按项目看 → + 创建项目 或项目首页的 创建项目 打开项目创建表单，选择可用的本地或云端项目来源，保存后进入新项目。项目列表及首页只汇总当前可见任务，并突出需要判断的项目；摘要使用实际任务状态，不推断风险或目标完成率。项目范围、列表查看方式、筛选、所选任务和视图保存在当前标签地址中，切换标签、刷新或重启后恢复。列表、项目和任务面板之间往返时保留已挂载面板的滚动位置。项目修改遵循原有权限及对应表单的保存操作。

时间线显示原始评论、执行、状态与转派记录。选择节点时，详情及可访问的私人讨论关联到同一个任务和节点；缺少来源或无权访问的内容不会被推断为新的会话。宽屏可并排使用列表、时间线和私人讨论，并拖动分隔线调整宽度。窄屏使用分步视图和返回操作。

时间线顶栏的附件图标切换 附件 筛选，文件夹图标打开所属项目；右上角 …（任务详情） 先打开任务摘要弹窗，显示真实描述、可见范围、状态及描述中明确列出的验收依据。弹窗中的项目按钮打开所属项目，关联项目与更多配置 进入原有详情编辑面板。编辑遵循现有权限和字段保存方式；点击描述进入编辑后，使用 保存 提交或 取消 放弃。关闭摘要弹窗或按 Escape，焦点返回任务详情入口；关闭编辑面板或在窄屏点击返回，回到同一任务时间线。

系统开启“减少动态效果”时，团队状态的入场、脉冲和活动轨迹停止播放。状态文字、图标和无障碍名称继续显示，状态切换不依赖动画表达。

私人讨论​

在任务时间线点击 私人讨论，打开当前用户原有会话。节点旁的入口只读展示已验证的来源轮次，不显示输入框或结论提交表单；来源无法确认时会显示提示。点击 继续当前讨论，回到同一会话及其未发送草稿，不新建会话或任务。普通私聊不会自动公开正文或更改共享任务状态。发送、排队及停止沿用原会话能力；当前若为共享执行，私人消息可排队或中断后开始私人讨论，不能直接引导共享轮次。发送失败时保留草稿。未发送输入按会话保存，刷新或重启后恢复。

要公开结论，在当前讨论输入区点击 查看建议结论，切换到同一面板内的 确认要提交的结论 预览。在 以下内容将对项目成员可见 中手动填写或编辑正文，核对任务标题，再点击 确认并提交结论。系统不会从私人历史或文件自动填入结论；只有你明确确认的正文会发布到当前任务。点击 继续讨论 返回原会话，普通输入和结论草稿都保留。即使会话没有历史消息，也可以从输入区进入预览并手动编辑。

共享结果出现在原任务时间线，原“协作”页也可读取。私人记录、未发送输入及附件不会随之发布。发布前会重新检查当前权限和归档状态；权限变化、归档或发布失败时保留预览及结论草稿，修复后手动重试。发布成功后返回讨论；如果评论已提交但时间线刷新失败，预览保留错误提示，已提交正文不会再次发送。返回讨论或切换任务会取消尚未完成的发布权限检查，关闭面板不会把草稿发到其他任务。

通知、深链与重试​

预览开启且实验标签已经打开时，项目任务通知和 wework://boards/... 深链复用该实验标签，更新目标项目与任务并保留列表筛选。预览关闭或尚未打开实验标签时，继续进入现有“协作”页。原“协作”入口始终打开原页。

实验专用深链为 wework://collaboration-exp?...，内部路由为 /collaboration-exp。链接保留项目来源、项目、任务、节点和讨论参数。云端项目仍需登录和现有访问权限；链接不授权操作。

模块加载失败或渲染出错时，仅实验标签显示错误提示。点击 重试 重新加载，其他任务与协作标签仍可切换。问题持续时关闭预览，并通过右上角 反馈问题 提供复现路径。
