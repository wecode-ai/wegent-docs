界面导航与功能位置

不知道某个功能在哪里时，先从本页查找入口，再阅读对应使用指南。本页描述桌面主窗口；弹窗、窄窗口和不同操作系统的布局可能不同。这里的路径是点击顺序，不是需要输入的命令。

先认识界面​

区域在哪里可以做什么
左侧栏主窗口左边新建任务、搜索、打开项目与历史对话；底部账户菜单进入设置
顶部标签栏主窗口上方在任务、协作（项目空间）、智能体等已打开页面之间切换；右侧 + 新建标签页
对话区任务页面中央阅读回复、查看工具执行过程、处理需要确认的请求
输入区对话区下方输入任务、添加附件、选择模型与权限、选择插件或 Skill
右侧工作区对话右边，可收起文件、审核、内置浏览器及其他工作区标签
底部面板对话下方，可收起终端等辅助会话
设置导航打开设置后的左边按个人、集成、编码、已归档分组选择设置页

左侧栏隐藏时，可用默认快捷键 Command+B 恢复；右侧工作区使用 Option+Command+B，底部面板使用 Command+J。这些是 macOS 默认值；其他系统及修改过的快捷键以 设置 → 快捷键 为准。

常见问题：我要去哪里​

想做什么（常见叫法）从哪里进入条件与详细说明
新建任务 / 新对话左侧栏 → 新建任务快速开始
搜索历史任务左侧栏上方 → 放大镜左侧栏展开后查找搜索图标
打开代码目录 / 添加项目左侧栏 → 项目分组旁的添加按钮 → 本地项目选择本机目录；远程目录选云端项目，见项目与工作区
在项目里新建对话左侧栏 → 对应项目 → 新对话入口先添加或打开项目；与独立对话的工作区不同
打开协作看板 / 项目空间 / Issue顶部标签栏 → + → 协作 → 选择项目已打开协作标签时直接切换；代码项目不等于项目空间，见项目与工作区
打开对话或 Issue 引用输入框或已发送消息 → 点击引用胶囊对话引用在当前任务窗格打开；Issue 引用打开或复用项目空间看板并定位 Issue；地址无法解析时不跳转，目标不可访问时在打开的任务或看板中显示错误，见与 AI 协作
从任务摘要打开 Issue / 看板输入框上方工作项摘要 → 标题、详情或看板图标标题打开当前工作项详情（无详情时打开看板）；详情和看板图标分别查看详情或定位看板；已有看板复用，见代码工作台
管理智能体顶部标签栏 → + → 智能体未连接云端时先显示连接流程；中文 Team 为智能体、Bot 为机器人
查看等待我回应的请求与项目事项顶部标签栏 → + → 待你处理汇总需要本人接手的事项，不是归档历史；见处理提问与项目待办
快筛某项目待我处理的 Issue协作 → 选择项目 → 看板工具栏 → 待我处理临时过滤，不改保存视图；见项目待办与等待时间
查看流程在我这里等了多久待你处理 → 选择项目事项或问题有可靠本轮交接证据才显示计时；见等待时长与流程分析
配置项目执行设备、仓库、初始化项目空间 → 项目设置 → 执行环境与全局设置的执行环境不是同一页；AI 执行前需在线设备完成初始化
项目 AI / 项目管理者项目设置 → AI 团队 / 自动处理当前入口与旧称差异见项目 AI 管理者；不要寻找旧版底部按钮
个人分身左侧栏 → 我的分身Beta 功能；版本不兼容时可从错误提示前往云端工作查看设备情况，见个人分身
确认分身配置调整我的分身 → 当前会话中的确认卡 → 确认并应用查看受影响角色和来源，成功后原会话显示实际变更；见对话调整
恢复已归档的分身来源工作我的分身 → 分身详情 → 近期活动旁箭头 → 对应工作 → 取消归档仅在工作已归档时显示；恢复不自动执行，见来源会话策略
停止分身 / 更换绑定左侧栏 → 我的分身 → 分身详情 → 管理分身 → 设置面板左下角“停止分身”整体停止并取消任务后才显示换绑选择；见实例绑定与停止
换模型 / 调推理等级任务输入区 → 模型选择器没有可用模型时去设置添加，见模型设置
添加附件、选择 Skill / 插件任务输入区 → + 或能力选择入口见与 AI 协作和插件与 Skills
切换只读、工作区、完整访问权限输入框左侧工具区 → 快捷短语右边的权限图标悬停查看当前模式；切换权限不等于授权外部应用
查看文件 / 编辑文件右侧工作区 → 文件先打开工作区；可写文本自动保存，见代码工作台
查看 Diff / 审核代码助手回复下方的文件变更 → 审核支持 Git 的任务；在执行设备读取变更
打开网页 / 预览网页右侧工作区 → 新标签页菜单 → 浏览器不是外部 Chrome，见内置浏览器
打开终端底部面板 → + → Terminal从当前任务工作目录启动；不会因展开面板而自动创建
查看版本 / 检查更新左下角账户菜单 → 关于 / 检查更新检查更新与关于是不同操作，见设置与数据

待回答的业务问题提供 先聊聊 入口：从任务问题卡片或 待你处理 的问题详情进入，会在原任务右侧栏打开讨论标签页，与浏览器、文件并列。用途与限制见处理 AI 的提问。

从侧栏的 项目 → 新建项目 → 云端项目 可在选择远程主机时添加设备，见项目与工作区。

找不到入口时​

  1. 先确认正在使用桌面主窗口，且左侧栏、右侧工作区或底部面板没有被收起。图标按钮可悬停查看名称。
  2. 确认所在上下文：任务里的模型选择、项目空间里的项目设置和应用全局设置不是同一层级。
  3. 检查 设置 → 通用 的功能模式与实验性功能。专注模式隐藏代码托管、工作树并关闭内置 Git 插件；实验性入口也可能被隐藏。不需要为查找普通功能开启完整访问权限。
  4. 云端能力检查连接状态与设备在线情况；项目管理操作检查当前项目角色；插件能力检查是否安装、启用及完成对应应用授权。不要把入口不存在直接判断为未登录。
  5. 查看 关于 中的版本，并说明系统、当前页面、目标功能及可见按钮。文档随应用版本提供；若仍无法对应，应报告文档缺口，不猜测菜单位置。

覆盖范围与更新​

本页是功能位置索引，详细操作保留在链接的专题文档中，避免复制多份流程。设置页和注册式侧栏入口通过真实 DSH 声明校验双语条目、名称、分组及显示条件；新增、删除、改名需在同一变更中更新本页。

输入区、项目菜单、账户菜单等非注册式控件仍需代码审查人工核对，自动测试不能证明所有按钮均已覆盖，也不能证明运行中界面的实际布局。维护规则见仓库 wework/AGENTS.md。构建会将中英文文档复制进内置 wework-docs，已安装的旧版本不会因仓库文档更新而即时变化。
