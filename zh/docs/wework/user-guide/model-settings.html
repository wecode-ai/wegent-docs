模型设置

在 设置 → 模型 中管理任务使用的模型。

模型页逐项操作​

从 左下角账户菜单 → 设置 → 个人 → 模型 进入；任务输入区的模型选择器只选择模型，不是服务商配置表单。

在已有会话中，通过 任务输入区 → 模型选择器 → 选择模型 → 切换模型 确认后，下一条消息使用新模型。 OpenAI 账号、自定义和云端模型之间切换也保留原会话、草稿及工作区面板，不会另建引用会话。 正在生成的回复仍使用原模型；可用选项及工具权限以所选模型和原有授权为准。

手机打开电脑上的已有会话时，恢复该任务保存的模型、服务商和推理参数，续发消息沿用这些设置。 模型目录暂未加载或读取失败时，仍保留任务的模型标识，不会换成新会话的默认模型。 手机上的手动模型选择仅作用于当前会话；其他会话和新会话各自保留自己的选择。 选定可用执行设备后即自动读取模型目录，智能等级与默认值沿用电脑端的能力解析，无需先打开模型列表。

功能点操作步骤与结果注意事项
本地 Codex 订阅切换订阅开关，按提示重启；展开查看模型或管理账号本机账号不等于 Wegent 云端账号
添加服务商模型添加模型 → 选择服务商并填写连接 → 在同一表单获取或手动添加模型 → 一次保存同组共享服务商地址及 Key，不要在聊天里填写密钥
自定义接口在服务商列表选择自定义接口，填写名称、协议、Base URL、Key协议必须与实际接口匹配；测试成功不等于拥有外部插件授权
编辑接口与增加模型接口分组 → 编辑 → 在同一表单修改共享配置或增加模型 → 保存共享配置影响同组模型；单模型的测试不测试整组
编辑模型能力展开接口 → 编辑模型，设置上下文、最大输出及能力最大输出为正整数；填写上下文时需小于上下文
视觉代理模型在文本模型的配置中选择明确支持图片输入的模型图片发送给视觉模型并转换为文字给主模型；云端引用须在 Wegent Web 配置
测试连接在表单中展开模型 → 测试连接，或在底部测试全部模型；失败后展开详情无需保存；不会改变已保存配置；空白 Key 编辑时沿用已保存值
Codex Catalog展开 Codex 模型列表 → 模型操作 → 编辑 Catalog；修改后保存或恢复默认不支持在此新增模型；可能提示重启执行器
停用、取消与删除使用模型或接口对应操作；取消不保存，删除前确认范围删除接口会移除其模型，但不删除已有对话
在任务中选择返回任务输入区，点击模型选择器，再选模型及可用推理等级当前任务支持哪些选项以模型能力为准；无模型时回设置恢复配置
  • Codex 订阅：开启本地订阅后使用本机 Codex 账号和模型。点击“查看模型”调整模型能力，点击“管理账号”登录或管理账号。更改本地订阅开关后需重启应用。开启本地订阅后，可在同一区域的“连接方式”选择 HTTP（默认）或 WebSocket，用于新对话。 在对话中可以请求模型生成图片或搜索网页。原生工具请求通过本地代理转发到 Codex 官方服务，工具是否可用取决于所选模型和订阅账号。
  • 自定义模型：点击“添加模型”，选择 DeepSeek 等服务商，填写连接名称和 API Key，在同一表单中获取服务返回的模型列表或手动添加模型，一次保存即可使用，无需切换步骤。可先保存不含模型的连接，稍后再添加模型；同一服务可用不同连接名称配置多个账号。
  • 自定义接口：在同一个服务商下拉列表末尾选择“自定义接口”，填写连接名称、API 协议、Base URL 和所需的 API Key，再获取或手动添加模型。
  • 云端模型：连接云端后查看服务端提供的模型。

已添加的模型按接口分组，同组模型共享地址和 Key。点击“编辑”，在同一表单中修改共享地址、协议、Key 和模型；预设服务的地址与协议位于“连接高级设置”。在模型列表上方按模型 ID 或显示名称搜索，刷新列表不会覆盖已配置模型的名称、能力或启用状态。展开分组后，点击“编辑模型”修改上下文长度、最大输出长度、模型能力及协议与工具设置。最大输出长度以 token 为单位，必须为正整数；填写上下文长度时，最大输出长度必须小于它。留空使用运行时默认值。

Codex 任务未显式指定上下文长度时，使用模型 Catalog 配置的上下文大小。最大上下文和自动压缩阈值是独立设置：例如最大上下文为 500,000、有效上下文比例为 95%，且未设置自动压缩阈值时，可用窗口约为 475k，默认自动压缩阈值约为 450k。

当模型配置了最大输出时，Codex 的自动压缩点按可用输入预算（上下文减去最大输出）的 80% 计算。Chat Completions 和 Anthropic Messages 未填写最大输出时，使用代理默认的 96,000 tokens 预留输出预算；未填写上下文长度时，使用所选 Wework Catalog 的窗口。例如 1,048,576 上下文、96,000 最大输出时，可用输入预算约为 952.6k，自动压缩点约为 762.1k。原生 Responses 未配置最大输出时，保留服务商默认值。

“设置 → 上下文”中的“上下文压缩阈值”（默认 75%）只控制上下文指示器何时显示手动压缩提示，不会修改 Codex 的自动压缩阈值。Codex 的自动压缩阈值由任务所用模型 Catalog 的上下文窗口、实际输出预算和模型配置共同决定。云端模型没有匹配到专用 Catalog 时，使用 wework-gpt-6.1-sol 兼容目录提供能力元数据，沿用原有共享目录链路，无需登录官方账号。该目录不限制模型配置的上下文窗口，也不启用官方专用的 code mode 或 Responses Lite。

添加或编辑模型时，可在同一表单中展开单个模型并点击“测试连接”只测试该模型，也可在对话框底部点击“测试连接”，测试当前填写的连接及所选模型，无需先保存。编辑时 API Key 留空会使用已保存的 Key。测试会检查接口鉴权和工具调用；成功显示“连接正常”，失败可展开详情，修改配置后重新测试。测试不会修改已保存的配置。

取消编辑不会保存；放弃未保存的修改时会要求确认。删除接口同时移除它的模型，不会删除已有对话。

本次配置界面改进不新增旧配置迁移、自动重新分组或旧数据清理。保留已有模型 ID、会话引用和已保存的密钥。

云端设备的模型目录同步确认​

在任务中选择需要同步到云端设备的本机模型时，先检查确认框中的设备和模型，再选择同步或取消。多个请求按顺序逐个确认；确认当前请求不会批准后续请求。同步期间不能重复提交或取消，失败时保留错误，可重试或取消。切换到下一条请求后，焦点回到取消按钮；处理完全部请求后，焦点返回原来的控件。

关闭确认框所在的界面会取消尚未确认的请求，不会自动同步；已经确认并开始的同步会继续完成。确认界面不可用时，调用方会收到取消结果，可在界面恢复后重新选择模型。

手机版的单模型与服务商配置​

从 设置 → 模型与账号 进入，OpenAI 账号仍使用原来的 Codex 登录流程，可独立于 Wegent 后端登录使用。

  • 单独配置的模型：保留原来的单模型入口。点击“单独添加模型”填写该模型自己的地址、API Key 和模型 ID；点击已有模型继续编辑。原有配置不会搬迁、合并或删除。
  • 模型服务商：点击“添加服务商”，选择预设或自定义兼容服务，填写连接名称和 Key，点击“保存并管理模型”。服务连接可暂时不含模型。
  • 模型管理：进入服务商后可搜索已配置模型，获取或刷新模型列表，或手动添加。点击模型编辑名称、上下文、最大输出、图片输入、并行工具等能力；高级设置可覆盖协议、路径、工具格式、视觉辅助模型和能力 JSON。JSON 修改需要先应用，错误文本会保留供修正。
  • 显示与测试：关闭“在模型选择器中显示”会保留配置；“测试此模型”只检测所选模型，不会保存草稿。获取模型列表和测试连接会请求对应服务；保存配置后本机执行就绪时同步可用模型。
  • 生效与失败恢复：模型能力通过与 PC 相同的 Catalog 接口写入，只有执行器空闲时才重启加载。忙碌时保留已保存配置并显示重试提示，不强制中断当前任务；原来的单模型和官方账号仍可继续使用。保存或同步失败保留编辑内容，可重试；并发修改会拒绝覆盖较新的配置。

两种配置分别保存，API Key 位于手机安全存储；只有发布到本机执行器的模型列表合并展示。连接、退出或切换 Wegent 后端账号不改变本机配置。取消或返回时，未保存的服务商和模型修改需要确认放弃；删除服务商前确认影响范围，已有对话保留。

自动回复建议位于 设置 → 通用 → AI 辅助，详见自动回复建议。
